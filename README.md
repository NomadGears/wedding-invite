# Sungjem & Swedevi — Animated Wedding Reception Invitation

A responsive floral-luxury wedding reception invitation website with a livelier blush, raspberry, coral, peach and plum palette.

## Features
- Tap-to-open ribbon cover with animated untying/reveal effect
- Floating petals and animated botanical ornaments
- Scroll reveal and hover animations
- Live countdown to the reception
- Google Maps directions
- Mobile responsive
- No church service details, dress-code section, or RSVP form

## Publish using GitHub Pages
1. Upload `index.html` and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Your site URL will look like `https://YOUR-USERNAME.github.io/wedding-invite/`.

The map button opens a Google Maps search for the venue; verify the pin before sharing.
