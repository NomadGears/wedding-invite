## Publish using GitHub Pages
1. Sign in to GitHub and create a **public** repository named `wedding-invite`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to deploy. Your link will look like `https://YOUR-USERNAME.github.io/wedding-invite/`.

The map button opens a Google Maps search for Naga Solidarity Park near New Secretariat, Kohima. Please verify the pin before sharing widely.
